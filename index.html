Privacy Policy for LexoNews

Effective Date: July 1, 2026

LexoNews is built as a free, open-source custom feed reader application. This service is provided at no cost and is intended for use completely as-is.

1. Absolute On-Device Data Isolation

Your personal data is an absolute architectural design choice of LexoNews. The application operates entirely locally on your physical device. All custom search operators, complex filter criteria, content processing rules, text-scoring configurations, and downloaded content caches are stored inside an isolated SQLite database on your device via the Room persistence layer. None of this content data is ever transmitted, collected, uploaded, or exposed to any external servers, third parties, or systems.

2. Anonymous Usage Analytics (Telemetry)

To optimize performance, diagnose issues on modern target platforms, and guide software updates, LexoNews collects lightweight, anonymous technical event signals. This pipeline is built with strict privacy constraints:

  • No Personally Identifiable Information (PII): The application never collects, views, or transmits names, email addresses, IP addresses, location data, or physical device serial numbers.
  • On-Device Cryptographic Masking: Upon the first installation, a random identifier is generated locally. This identifier is immediately processed using a secure, one-way SHA-256 cryptographic hash directly on the device. The raw identifier is never stored or transmitted over the air.
  • Direct Transmission Channel: Telemetry signals are pushed securely over HTTPS directly to our ingestion endpoint at nom.telemetrydeck.com, bypassing generic background tracking engines or third-party behavioral tracking loops.

3. Network and External Connectivity

LexoNews establishes direct HTTPS network connections directly to the public RSS or XML feed targets specified by you. No intermediary proxy server is utilized. Outside of the anonymous performance telemetry described in Section 2, the application does not deploy tracking cookies, advertisement networks, or behavioral frameworks.

4. Data Deletion and Control

Because your configuration profile and local installation hash live exclusively on your device, you possess total sovereignty over it. Clearing the application's cache or data via the Android System Settings panel—or completely uninstalling the application—instantly and permanently purges every trace of data and the anonymous identifier from the device's storage media.

5. Changes to This Policy

This privacy documentation may be modified periodically to accurately reflect technical changes in the application architecture. You are advised to review this page occasionally for any updates.
